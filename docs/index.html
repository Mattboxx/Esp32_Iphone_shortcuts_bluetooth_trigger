The "when this turns on, do that" building block

🛴 Scooter, bike, car

Ignition on → open your navigation or dashboard app, start a ride timer, set the volume.

🖥️ Desk & workshop

Desk lamp or monitor on → Work Focus on. 3D printer powered → start a timer, log it.

🚪 Doors & sensors

Switch mode: a reed switch or relay opens → your iPhone gets the event.

🔘 A real button

Pulse mode: press a button → it connects for a few seconds → Shortcut runs.

🏠 Home Assistant

Shortcuts can call Home Assistant, webhooks or HomeKit, so one trigger can drive the whole house.

🌙 Bedside

Night lamp on → Sleep Focus, alarm set, lights dimmed. Lamp off → turn it back.

How it works

  1. FlashPlug the board into your computer, choose a name and options below, click Install.
  2. Pair onceiPhone → Settings → Bluetooth → tap your device. No PIN.
  3. AutomateShortcuts → Automation → Bluetooth → your device → "Is Connected" → add actions → Run Immediately.

The board appears as a mouse that never moves. iOS treats it like any other Bluetooth accessory, and your on-screen keyboard keeps working (a "keyboard" device would hide it). Connecting is the signal; nothing is ever typed or clicked.

Two ways to trigger it

⚡ When it gets power

Wire nothing: power the board from the thing you want to detect (a scooter's USB port, a car socket, a lamp's USB charger). Power on = connected.

📍 When a pin is activated

The board stays powered and connects when a pin you choose changes: a reed switch on a door, a relay, a push button, a sensor output. You set the pin, level, resistor, debounce and timing.

Install from your browser

Uses Web Serial in Chrome, Edge or Opera on a computer (Windows, macOS, Linux, ChromeOS). Nothing to install.

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. Safari, Firefox and iPhone/iPad don't support Web Serial. You can still download the firmware and flash it with esptool.

    Connect your board

    Plug the ESP32 in with a data USB cable (some cables only charge), then click Connect and pick its port.

    Port not listed / can't connect?
    • Try another cable or USB port. A charge-only cable is the #1 cause.
    • Install the USB driver for your board's chip: CP210x or CH340/CH343.
    • Hold the BOOT button, tap RESET/EN, release BOOT, then click Connect again.
    • Close other programs using the port (Arduino IDE, serial monitors, Cura…).

FAQ

    
Power-on or pin trigger: which one do I need?
      
Power-on if the thing you want to detect can power the board (USB port, 12 V socket with a USB adapter, a lamp's charger). Pin if the board is always powered and you want to react to a contact: door reed switch, relay, button, the output of another device. It's one firmware: you can switch later with Save settings only, in a second.

      
With a pin trigger the board stays visible until a phone is paired, so you can pair it before wiring anything. After that it only connects when the pin is active.

    
Which boards work?
      
Any original ESP32 (DevKit, WROOM, WROVER, PICO, D1 mini32, M5 Atom, ESP32-CAM, TTGO…), including single-core and 26 MHz-crystal variants. It uses Classic Bluetooth HID, the mode this project was first tested with on iPhone (v1; the v2 rewrite is being verified).

      
ESP32-C3, ESP32-S3 and ESP32-C6 have no Classic Bluetooth, so they get a Bluetooth LE HID mouse (HID over GATT, the same protocol as BLE mice and keyboards). tested on iPhone with a Waveshare ESP32-S3-Zero. ESP32-C3 and C6 run the same code but are still beta until someone confirms them: if you try one, please report back.

      
Not compatible: ESP32-S2 and ESP8266 (no Bluetooth). Any flash size from 2 MB works.

    
Why a mouse and not a keyboard or a "beacon"?
      
The Shortcuts "Bluetooth" automation only lists accessories paired in Settings, and iOS only pairs certain device types from there: audio, keyboards, mice, game controllers. A plain BLE beacon never shows up. A keyboard would hide your on-screen keyboard while connected. A mouse has no side effects except an optional on-screen pointer.

    
Does it work with several iPhones?
      
Yes. Several phones can pair. The board calls back the last one that was connected first, then the others. Only one is connected at a time.

    
Is it private / secure?
      
Nothing leaves your phone: no account, no internet, no app. The firmware sends no input at all. Use the pairing window option if you don't want strangers to see or pair the device.

    
How do I re-pair or reset it?
      
Hold the configured button for 5 seconds (LED flashes red/fast), or reinstall with "Forget paired phones" ticked. Then on the iPhone, tap the device → Forget This Device and pair again.

    
Can I change the settings later?
      
Yes. Connect the board here again: your current settings are read back from it, and Save settings only rewrites just the 4 KB settings block in a second, keeping your pairing.

    
Power consumption?
      
Roughly 30–60 mA while connected depending on the board, so it's meant for things that are powered anyway (vehicles, USB ports, chargers). It's not a coin-cell device.
